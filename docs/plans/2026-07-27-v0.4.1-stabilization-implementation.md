> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

### Task 8: Anchor and bound the restricted Windows journal

**Files:**
- Modify: `internal/windows/restricted_journal.go`
- Modify: `internal/windows/restricted_journal_test.go`

**Step 1: Write failing adversarial tests**

Add tests for:

- an oversized record is retained as corrupt without unbounded decoding;
- a symlink/reparse-style non-regular record is not followed;
- a replaced records directory cannot redirect record creation outside the
  opened journal root;
- valid records still survive reopen, sweep, and completion.

Use platform-appropriate skips only where the host cannot construct a reparse
point; the regular-file and size tests must run everywhere.

**Step 2: Verify RED**

Run:

```bash

```

Expected: at least the oversized/unanchored cases fail.

**Step 3: Implement root-relative journal access**

Open an `os.Root` for the journal state during `OpenRestrictedJournal`. Store
record names, not ambient absolute paths. Use root-relative open/create/remove
operations, `Lstat`-equivalent metadata checks, and `io.LimitReader` with a
small explicit maximum record size before JSON decode.

**Step 4: Preserve durability and cleanup semantics**

Keep exclusive creation, file sync, directory durability where supported,
permanent SID retirement, corrupt-record retention, and exact ACE validation.

**Step 5: Verify and commit**
